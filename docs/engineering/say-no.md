# say-no

## What it does

Writes the sentence a person would hear if they asked for a capability the pack excluded. Output is `docs/foundation/10-refusals.md`. Each refusal names the screen or requirement that exists instead.

## When to reach for it

A stakeholder asks for something the pack marked later, out, or do-not-build.

## Common questions

**Can the answer be a soft deferral?** No. The line is a refusal, and it points at what the product does instead.

**What if a request should change the pack?** The file can record that verdict. It does not silently add the feature.

## It's working if

Each entry has what they asked, what we say, who owns the no, and what would make it real later.
