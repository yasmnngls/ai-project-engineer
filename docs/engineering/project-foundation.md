# project-foundation

## What it does

Writes `docs/foundation/` in one pass: brief, PRD, personas, user journeys, sitemap, system design, data and API, MVP slice, and risks. Facts are tagged stated, inferred, or assumption.

## When to reach for it

A repo is empty, or nearly empty, and someone describes a product to build. Also when they ask for a PRD, a sitemap, a user journey, or the docs an engineer needs before code.

## Common questions

**Does it start coding?** No. Implementation is a later skill, and only if you ask.

**What if the user or the job is missing?** It asks once and waits. It does not draft a pack from a blank prompt.

**Can it copy the Site Log example?** No. `examples/field-notes` is a fixture for the validator.

## It's working if

`docs/foundation/` has the ten files, the validator passes, and the reply is a short closeout rather than the pack pasted into chat.
