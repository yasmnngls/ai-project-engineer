# Trial shape

```markdown
# Assumption trials

## Trials

### A1 {short name}

- Claim: {the assumption sentence, copied, still tagged [assumption]}
- Left alone: {the table, route, or decision we will build if nobody checks}
- Kill test: {one conversation, one count, or one click. Name the person or the artifact.}
- Result that flips it: {an observable outcome, not a feeling}
- If it flips: {which FR ids change status, and the one container or route that appears or disappears}
- Expensive after: {the build-order step after which undoing this deletes code}
```

Number `A1` upward. One claim per block.

`Result that flips it` has to be something a person could observe in one sitting. "Users don't like it" is not a result. "The office cannot match the typed name to a technician on last week's visits" is.

`If it flips` cites ids that already exist, or says a new id would be required. It does not draft that requirement.

If `08-risks.md` says there are no assumptions, the file is only:

```markdown
# Assumption trials

## Trials

No assumptions. There is nothing to try.
```
