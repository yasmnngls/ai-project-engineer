# Engineering

Skills for founding a product and building one beat of it.

## Model-invoked

The model can reach these when the task fits. You can also type the slash command.

- **[project-foundation](./project-foundation/SKILL.md)**: Writes the ten-file foundation pack before any product code.
- **[architecture-memory](./architecture-memory/SKILL.md)**: Writes `ARCHITECTURE.md` and the craft rules the next session reads.
- **[one-chunk](./one-chunk/SKILL.md)**: Implements one beat of the MVP: contract, shell, or wire.
- **[lock-contracts](./lock-contracts/SKILL.md)**: Writes Zod schemas and discriminated results before UI.
- **[state-shell](./state-shell/SKILL.md)**: Builds one screen as a state union plus a presentational view.
- **[assumption-trial](./assumption-trial/SKILL.md)**: Writes a kill test for each load-bearing assumption.
- **[say-no](./say-no/SKILL.md)**: Writes the refusal for each excluded capability.
- **[spec-drift](./spec-drift/SKILL.md)**: Compares the code to the pack and reports contradictions, gaps, and hardened assumptions.

## User-invoked

None. These skills stay reachable by the model so a sentence can start them.
