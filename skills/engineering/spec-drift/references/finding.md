# Finding shape

```markdown
# Drift

## Verdict

drift

## Findings

### D1 {short name}

- Kind: contradiction
- Spec: {file and the id or decision that forbids or requires this}
- Code: {path a person can open}
- What to do: {remove the code, or change the pack first. One sentence.}
```

`## Verdict` is the single word `drift` or `clear`.

`Kind` is `contradiction`, `gap`, or `hardened`.

`Code` is a repository path, or the exact sentence `No product code yet.`

When the verdict is `clear`:

```markdown
# Drift

## Verdict

clear

## Findings

None. The code still matches the pack.
```

Do not list clean requirements. Silence means they still match.
